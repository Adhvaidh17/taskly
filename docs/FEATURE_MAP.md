# Feature locations

| Feature | Location in app |
|---|---|
| Create account | Login screen → Create account |
| Create group | Profile → Create group |
| Join by group ID | Profile → Join group |
| Share group ID | Profile group card or Group info |
| Find Taskly contacts | Chats → New chat, or Profile → People on Taskly |
| Direct chat | Tap a matched Taskly contact |
| Group chat | Chats → select group |
| Mention a person | Type `@` in the message field |
| AI task suggestion | Under the sender's message after analysis |
| All visible tasks | Tasks → All |
| Tasks assigned to logged-in user | Tasks → Assigned to me |
| Tasks created for others | Tasks → Tasks I assigned |
| Task status | Task card/detail; assignee only |
| Notifications | Bell icon in the main top bar |
| Group members and ID | Tap chat header → Group info |
| Reply/react/edit/delete/pin | Long-press a message |
| Mute/archive | Long-press a conversation in Chats |
| Archived conversations | Chats → Archived filter |
